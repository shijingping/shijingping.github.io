A Java console program that reads nine single-digit values, arranges them in a 3×3 matrix, and calculates the sum of every row, every column, and both diagonals.

01 / PROJECT OVERVIEWLAB_001

About this activity

This activity demonstrates how a two-dimensional array stores values in rows and columns. The program uses nested loops to collect input, validates that every value is from 0 to 9, and computes the required totals.

3 × 3 matrix size
02 / OBJECTIVEGOAL

What the program does

Accept nine valid numbers, display them in matrix form, calculate row and column totals, calculate two diagonal totals, then let the user choose whether to run the program again.

03 / WORKFLOWSTEPS

Program flow

  1. Declare a 3×3 integer array.
  2. Read and validate nine inputs.
  3. Calculate row and column sums.
  4. Calculate both diagonal sums.
  5. Display results and ask to retry.
04 / CORE LOGICJAVA

Array calculations

Nested loops visit each matrix element. The indexes identify whether a value belongs to a row, column, or diagonal.

rowSum[i] += matrix[i][j];
colSum[j] += matrix[i][j];
